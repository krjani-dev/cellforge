# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| `0.0.x` (`@dev`) | Yes — latest patch only |

Pre-1.0 versions receive security fixes on the latest published patch. Older patch versions are not backported.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report security issues privately by emailing **devbyjani@gmail.com**. Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof-of-concept
- The version of cellforge affected
- Any suggested fix, if you have one

You can expect an acknowledgement within 3 business days. We will work with you to assess and address the issue before any public disclosure.
